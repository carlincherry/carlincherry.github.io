## Grad School Data Science

**Predict Whether I'll Like a Restaurant**
A hybrid recommendation system that predicts user-business ratings using Yelp data. Combines item-based collaborative filtering using Pearson similarity with an XGBoost model-based system.

**How Should I Live My Life?**
An LSTM generative text model trained on Bertrand Russell's writings to see if a neural network (RNN) could produce philosophy. This was before the popularization of LLMs made text generation look easy. The model's best attempt at existential wisdom was *"hghahahghg ghaihf shshshs."*
